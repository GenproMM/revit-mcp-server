# Слои проекта — инструмент, мост, маршрут, Revit API

Четыре слоя, каждый со своей ответственностью и своим набором разрешённых
зависимостей. Слой никогда не перескакивает через соседа.

## 1. Слой MCP-инструментов — CPython, async

- **Назначение:** выставить возможности Revit как MCP-инструменты со схемами,
  выведенными из докстрингов и тайп-хинтов.
- **Где:** `tools/`
- **Содержит:** асинхронные функции под `@mcp.tool()`, сборку словарей аргументов,
  вызовы `format_response`.
- **Зависит от:** `mcp.server.fastmcp`, внедрённых `revit_get` / `revit_post` / `revit_image`.
- **Используется:** MCP-клиентами через `main.py`.

Слой ничего не знает про HTTP: он получает вызываемые объекты аргументами
([[Транспорт внедряется в модули инструментов, а не импортируется]]).

## 2. Слой транспорта и моста

- **Назначение:** HTTP-обвязка, пул соединений, приведение исключений к строкам,
  декодирование картинок.
- **Где:** `main.py` — `_get_client`, `_revit_call`, `revit_image`.
- **Зависит от:** `httpx`, `anyio`, `uvicorn` (в комбинированном режиме).
- **Используется:** каждым модулем инструментов.

Здесь исключение перестаёт быть исключением и становится строкой
([[Ошибки не выбрасываются, а возвращаются строками]]).

## 3. Слой маршрутов Revit — IronPython, sync

- **Назначение:** настоящая BIM-работа — коллекторы, геометрия, транзакции, экспорт.
- **Где:** `revit_mcp/`
- **Содержит:** обработчики `@api.route(...)` с сигнатурой `(doc, request)`.
- **Зависит от:** `pyrevit.routes`, `pyrevit.revit`, `pyrevit.DB`, `System`.
- **Используется:** слоем моста по HTTP.

Единственный слой, где вообще упоминается Revit API
([[Паттерн обработчика маршрута — валидация, транзакция, сериализация]]).

## 4. Слой хелперов Revit

- **Назначение:** совместимость между Revit 2024–2027 и безопасность.
- **Где:** `revit_mcp/utils.py`
- **Содержит:** `get_element_id_value`, `make_element_id`, `suppress_warnings`,
  `sanitize_string`, `get_element_name`, `find_family_symbol_safely`.

Самые важные и при этом полностью непокрытые тестами функции репозитория.
См. [[ElementId читается и создаётся только через хелперы]] и
[[Каждая транзакция глушит модальные диалоги Revit]].

## Точки входа

**`main.py` (`__main__`).** Транспорт выбирается из argv: по умолчанию `stdio`,
плюс `--sse`, `--http` / `--streamable-http`, `--combined`.
См. [[MCP-клиенты подключаются четырьмя транспортами]].

**`run_combined_async`.** Вливает SSE-маршруты в Starlette-приложение
streamable-http и поднимает оба под одним uvicorn.

**`startup.py`.** Вызывает `register_routes()` на уровне модуля — то есть в момент
загрузки расширения pyRevit. Любой провал импорта логируется и перебрасывается
дальше, обрывая регистрацию целиком.
