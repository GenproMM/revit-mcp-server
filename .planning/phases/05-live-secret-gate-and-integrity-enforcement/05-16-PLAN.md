<objective>
Wire the two production entry points of the gate that 05-01 built and proved on `/create_level/`.
The tracer sends a real tool call through `bridge.revit_post`, which now puts the loaded secret under
`_mcp` on every POST, over a MockTransport into the real `security.gate_or_response` and on to a
handler that never sees the envelope. Then `startup.py` calls `security.initialize` once at extension
load, so the deployed extension opens its gate with its own secret and integrity verdict, and a
failure there is visible and keeps every gated route closed.

Purpose: SEC-02 (the secret travels in the body on the proven `text/plain` path), SEC-03 and SEC-06
(refusals reach the model as visible errors without the secret), INTG-02 and INTG-07 (the integrity
verdict is taken at load; unverifiable does not block startup), D-01 (startup only initializes state,
no wrapper), D-07 (strict 401, no grace), and the CONTEXT discretion item "envelope on every POST, open
reads included". This plan was split out of 05-01 to keep each plan inside the smart-zone budget; it
runs in wave 2 beside the fan-out 05-02..05-05, with which it shares no file.

Output: the `revit_post` envelope path and the lazily memoized secret in `bridge.py`, the security
initialization block in `startup.py`, the conftest pin, the end-to-end bridge test and the startup rows.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model tool arguments -> bridge request body | model-built data could try to pre-seed the reserved `_mcp` key |
| MCP server process -> pyRevit Routes (HTTP POST) | the secret leaves the process in every POST body; the reply text goes back to the model |
| extension files on disk -> security state at load | the secret file and the manifest are read once at load and trusted for the session |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Denial of service turned open door | security.initialize failure at extension load | high | mitigate | startup records it in registry.FAILED["security"] so /status/ is degraded, and `_STATE` stays None so every gated route answers 401 server_not_configured (Task 2 rows: stub raising, module missing, check_integrity raising) |
| T-05-05 | Spoofing | model-built `_mcp` in tool data | medium | mitigate | with_envelope refuses; revit_post returns NOT sent before _dispatch; transport sees no POST (Task 1) |
| T-05-06 | Repudiation | pre-send refusal mislabelled as outcome unknown | medium | mitigate | envelope built before _dispatch, tagged not-sent (Task 1) |
| T-05-07 | Information disclosure | unit tests reading the developer's real secret | low | mitigate | conftest pins the bridge secret cache to None (Task 1) |
| T-05-65 | Information disclosure | bridge reply texts and the stdio stream | medium | mitigate | the NOT sent text is fixed and carries neither body nor secret; the 401 rows assert TEST_SECRET is absent from the model-visible text; bridge.py never prints (Task 1) |
