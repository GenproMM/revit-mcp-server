# Аудитория — BIM-инженеры на Windows с Revit и pyRevit

## Портрет пользователя

Проектировщик, BIM-координатор или BIM-менеджер, который:

- работает в Autodesk Revit ежедневно, на Windows 10/11;
- уже знает про pyRevit — или готов его поставить (свободный аддон);
- умеет пользоваться ИИ-ассистентом (Claude Desktop, Cursor, Copilot);
- **не обязан** уметь программировать на Revit API.

Последний пункт — суть предложения. Порог входа в автоматизацию Revit исторически
проходит через IronPython и Revit API; продукт заменяет это описанием задачи словами.

## Технический барьер входа

Барьер всё же есть, и он не нулевой:

| Шаг | Сложность |
|---|---|
| Установить pyRevit | низкая — `.exe`, все дефолты |
| Включить Routes Server | низкая, но неочевидная — Settings → Routes → чекбокс |
| Поставить расширение | средняя — либо из панели Extensions, либо копирование в `%APPDATA%` |
| Поставить `uv` и `uv sync` | средняя — требует комфорта с терминалом |
| Настроить MCP-конфиг клиента | средняя — правка JSON |

README расписывает это в пять шагов с проверкой связи на каждом. Это разумно: аудитория
терпима к настройке, но не к отладке.

Полностью — [[Деплой — это два локальных процесса на рабочей станции инженера]].

## Кто НЕ аудитория

- **Пользователи не-Windows** — Revit там не работает, и обойти это нельзя.
- **Команды, которым нужен серверный/облачный сценарий** — продукт локальный по
  построению, один документ и один экземпляр Revit
  ([[Порт 48884 захардкожен, настраивается только хост]]).
- **Организации с требованиями к безопасности** — аутентификации нет, а `execute_code`
  исполняет произвольный код ([[execute_code даёт неаутентифицированное исполнение кода внутри Revit]]).
- **Пользователи нелатинских моделей — частично.** Имена элементов с кириллицей
  приходят как `?`, что делает часть инструментов практически непригодной
  ([[sanitize_string превращает кириллицу в вопросительные знаки]]). Для
  русскоязычной практики это существенное ограничение.

## Практические сценарии, на которые он рассчитан

1. **Координация** — найти коллизии конструкций и MEP, разобрать список, поправить.
2. **Массинг и черновая геометрия** — быстро собрать объём, уровни, каркас.
3. **Пакетная правка параметров** — раскраска по значению, установка параметров,
   маркировка.
4. **Документирование** — листы, спецификации, размеры, экспорт.
5. **Обмен** — IFC-экспорт, импорт DWG/SAT/SKP для наложения на существующее.
6. **Аудит модели** — статистика, ведомости материалов, данные по помещениям.

## Требования к рабочему месту

Одинаковые для разработки и эксплуатации — это локальный инструмент:

- Windows 10/11
- Revit 2024 / 2025 / 2026 / 2027 с открытым документом
- pyRevit с включённым Routes Server (для 2027 — сборка pyRevit с поддержкой 2027)
- `uv` в PATH
