# Раннер живого шлюза фазы 5 слал пустое тело и падал на хвостовой строке моста

**Симптом.** Первый боевой прогон `tests/test_phase5_live_gate.py run --stage match` дал `PHASE5_GATE_STOP`, `POSTS_SENT=7`. Причины остановки: `steps.r_levels_open.http: expected 200`, `steps.r_levels_wrong.http: expected 200`, `steps.b_wrong.text: expected Error: 401 - mismatch`. При этом сам продукт вёл себя верно: запросы без секрета и с чужим секретом получили 401, авторизованный `create_level` закоммитился.

**Причины (обе в раннере, не в шлюзе).**
- Шаги `r_levels_open` и `r_levels_wrong` слали в `/document_levels/` пустое `{}`; настоящему маршруту нужен селектор `document` из `/documents/` и он отвечал 400 `document-selector-required`. Оффлайн-фейк возвращал 200 на любое тело, поэтому тесты были зелёными.
- `_error_body` разбирал как JSON всё, что идёт после `Error: 401 - `, а мост добавляет вторую строку `Verified Revit process: PID ...`; разбор падал, и шаг `b_wrong` не находил `auth: mismatch`.

**Починка** (коммит `9aa9876`). Тело `/document_levels/` теперь `{"document": <селектор>}`, селектор берётся из записи preflight; `_error_body` читает только первый JSON-объект через `json.JSONDecoder().raw_decode` и игнорирует хвост. Оффлайн-фейк `_Client` теперь отвечает 400 без селектора, фейк моста добавляет хвостовую строку, плюс два новых теста.

**Урок.** Оффлайн-фейк маршрута должен проверять контракт тела, иначе он скрывает ровно тот дефект, ради которого стадия одноразовая. Первая же попытка (preflight-стоп `POSTS_SENT=0`) показала другое: перед запуском нужно убедиться, что в Revit открыт документ (`/documents/` вернул `count: 1`), а не только что слушатель один.
