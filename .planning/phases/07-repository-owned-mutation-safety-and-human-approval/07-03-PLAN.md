<objective>
Make the fleet payload start with mcp 1.30 (D-24). Since mcp 1.11 the SDK imports pywin32 on Windows
unconditionally, and pyRevit's embeddable CPython ignores `.pth` files, so `import mcp` fails in the payload
layout with `No module named 'pywintypes'` (reproduced by research). Add the same small path shim to the three
payload entry points, prove it offline, then prove the real recipe end to end with a local scratch payload and
the three HTTP transports.

Purpose: SAFE-19 (payload import, three transports). Runs beside the tracer (07-02) because it touches only
deploy entry points and new scripts.

Output: the shim in `deploy/server.py`, `deploy/gate.py`, `deploy/warm.py`; `tests/unit/test_deploy_libpaths.py`;
`scripts/scratch_payload_gate.py`; `tests/test_transports_smoke.py`.
