<objective>
Lead the phase with one thin, production-quality slice through every layer it touches: a tool call
from an MCP client passes the registration wrapper (contextvar call state, injected `user_request`
parameter), the production bridge, the new `audit.py` entry builder and its queue-backed roll-forward
JSONL writer, and comes back to the model as `format_response` text ending in `Audit: call_id <id>`.
Then ship the slice: the payload copies `audit.py`, the payload test follows imports transitively,
the cold start gate and the whole unit suite stay green.

Purpose: proves the architecture of D-01 (CPython side, one writer per server process, outcome from
provenance and the reply body, never from `format_response`), D-05 (call_id through a contextvar set
by a wrapper of `mcp.tool`, no edit to the 59 tool functions), D-07 (the Audit line), D-12 (the
injected optional parameter), D-14/D-15/D-17/D-18 (local per-user directory, file per process,
stdlib logging behind a queue, never break a call) on the agent's best context, before the expansion
plans 06-02..06-05 fill in the outcome table, the request content, correlation details and the
retention rules. AUDIT-01/04/05 start here.

Audit line in `tools/utils.py`; conftest isolation; `tests/unit/audit_support.py`;
`tests/unit/test_audit_tracer.py`; the payload copy line and the transitive payload test.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client -> tool wrapper | the model supplies tool arguments and the injected user_request |
| MCP server process -> local filesystem | entries leave the process into %LOCALAPPDATA%\RevitMCP\audit (or REVIT_MCP_AUDIT_DIR) |
| MCP server process -> stdout | stdout is the stdio protocol stream; any stray byte corrupts the session |
