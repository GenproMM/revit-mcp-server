2а. Routes без host — ограничить петлевым адресом
------------------------------------------------
Без строки host pyRevit слушает 0.0.0.0, то есть Routes этого ПК (а с ним
выполнение кода внутри Revit) доступен всей сети. Установщик такое
состояние не принимает и сам настройки не меняет; в CLI pyRevit команды
для host нет. Добавление host = "127.0.0.1" только СУЖАЕТ доступ до этого
ПК. Строка добавляется только если её нет; существующий host не менять.
Revit должен быть закрыт. Выполнить в PowerShell одним блоком:

     & {
       $ini = "$env:APPDATA\pyRevit\pyRevit_config.ini"
       if (Get-Process Revit -ErrorAction SilentlyContinue) { throw 'STOP: Revit is running' }
       $bytes = [IO.File]::ReadAllBytes($ini)
       $bom = $bytes.Length -ge 3 -and $bytes[0] -eq 0xEF -and $bytes[1] -eq 0xBB -and $bytes[2] -eq 0xBF
       $text = (New-Object Text.UTF8Encoding($false)).GetString($bytes)
       if ($bom) { $text = $text.Substring(1) }
       $nl = if ($text.Contains("`r`n")) { "`r`n" } else { "`n" }
       $m = [regex]::Match($text, '(?ms)^\[routes\][ \t]{0,}\r?\n(.{0,}?)(?=^\[|\z)')
       if (-not $m.Success) { throw 'STOP: no [routes] section' }
       $body = $m.Groups[1].Value
       if ($body -match '(?im)^[ \t]{0,}host[ \t]{0,}=') { throw 'STOP: host is already set, do not change it' }
       $add = 'host = "127.0.0.1"' + $nl
       if ($body -notmatch '(?im)^[ \t]{0,}port[ \t]{0,}=') { $add += 'port = 48884' + $nl }
       New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\RevitMCP" | Out-Null
       [IO.File]::WriteAllBytes("$env:LOCALAPPDATA\RevitMCP\pyRevit_config.before-routes-host.ini", $bytes)
       [IO.File]::WriteAllText($ini, $text.Insert($m.Groups[1].Index, $add), (New-Object Text.UTF8Encoding($bom)))
       'added: ' + $add.Trim()
     }

   port = 48884 добавляется, только если строки port тоже нет: это
   значение pyRevit и так использует по умолчанию. Повторить проверку
   из раздела 2, п. 3: должны быть enabled = true и host = "127.0.0.1".
   Резервная копия: %LOCALAPPDATA%\RevitMCP\pyRevit_config.before-routes-host.ini
   (вернуть её можно только при закрытом Revit).


2б. Движок IronPython 2.7 — переключить на IronPython 3 (IPY342)
----------------------------------------------------------------
Расширение RevitMCP рассчитано на IPY342 (стандарт парка). Под IPY2712
оно загружается и проходит проверку целостности, но не видит общий
секрет: все изменения модели отвечают 401 server_not_configured.
Переключение меняет движок для ВСЕХ расширений pyRevit этого ПК — это
согласованное действие пилота. Revit должен быть закрыт
(Get-Process Revit ничего не выводит).

1) Имя клона — первое слово строк из п. 2.4 (обычно master).
2) В той же сессии PowerShell, где задан $pyrevit (п. 2.4):

     & $pyrevit attach master 342 --attached

   (master заменить на имя клона, если оно другое).
3) Повторить п. 2.4: во ВСЕХ строках должно быть Engine: IPY342.
   Ошибка команды или после неё осталась IPY2712 — СТОП.
Вернуть прежний движок (& $pyrevit attach master 2712 --attached) —
только по согласованию с ответственным за пилот.

     $line | Set-Content -Encoding UTF8 "$env:LOCALAPPDATA\RevitMCP\userextensions-before-pilot.txt"
     $paths = foreach ($x in (($line -replace '^\s{0,}userextensions\s{0,}=\s{0,}', '') | ConvertFrom-Json)) { [string]$x }
     $old = @($paths | Where-Object { $_ -match '\\06_RevitMCP\\' -and $_ -match '\\ext$' })
     $pyrevit = (Get-Command pyrevit -ErrorAction SilentlyContinue).Source
     if (-not $pyrevit) { $pyrevit = @("$env:APPDATA\pyRevit-Master\bin\pyrevit.exe",
         "$env:ProgramFiles\pyRevit-Master\bin\pyrevit.exe") | Where-Object { Test-Path $_ } | Select-Object -First 1 }
     "pyrevit: $pyrevit"
     foreach ($p in $old) { "forget: [$p]"; & $pyrevit extensions paths forget $p }
     (Select-String -Path $ini -Pattern '^\s{0,}userextensions\s{0,}=' -Encoding UTF8).Line

6. Первичная проверка после запуска (только чтение)
---------------------------------------------------
1) После полной загрузки Revit:

     Get-NetTCPConnection -LocalPort 48884 -State Listen

   Нужна ровно одна строка, LocalAddress 127.0.0.1 (0.0.0.0 — СТОП:
   Routes открыт сети). Если установщик сообщил другой порт —
   использовать его.
2) В браузере: http://127.0.0.1:48884/genpro_revit_mcp/status/
   Нужны "health": "healthy", api_name genpro_revit_mcp, permit protocol 1.
   "degraded" — не успех: прочитать alerts. Если там "holds no shared
   secret" / secret configured false (мутации отвечают 401
   server_not_configured) — шаг 4.
3) В Hermes: «Проверь состояние Revit инструментом get_revit_status.
   Ничего не изменяй».
4) Только если расширение не видит секрет. Секрет читается ОДИН раз при
   загрузке Revit из папки зарегистрированного расширения. Диагностика —
   отдельный файл рядом с этой инструкцией; он только читает и НЕ выводит
   содержимое секрета. Запустить ОДНОЙ строкой (cmd.exe или PowerShell):

     powershell -NoProfile -ExecutionPolicy Bypass -File "\\srv-dfs\BIM\06_RevitMCP_pilot\diag-secret.ps1"

   Текст скрипта в консоль не вставлять: многострочная вставка в консоль
   ломается. Пользователю показать ВЕСЬ вывод (строки our paths: ...,
   extension secret: ..., revit-mcp-server | ..., status: ...).
   Если запуск запрещён политикой — СТОП, сообщить ответственному за пилот.

   Как читать результат:
   - our paths не 1 — вернуться к п. 5.2.
   - есть строка Engine: IPY2712 — это и есть причина: закрыть Revit,
     выполнить раздел 2б, запустить Revit заново и повторить п. 1–2.
     Переустановка не нужна.
   - local extension copy: True, или строк "revit-mcp-server |" из
     pyrevit env больше одной, или её Installed ведёт НЕ в
     06_RevitMCP_pilot — СТОП: Revit может грузить другую копию
     расширения. Копии не удалять самому. Строки других расширений
     (например revit-mcp-python) не наши, их не трогать.
   - failed_domains содержит security — СТОП с выводом скрипта.
   - extension secret MISSING или NOT readable — СТОП. Это проблема
     раздачи на сервере (файла нет или у пользователя нет права чтения),
     на ПК она не чинится. Передать вывод скрипта ответственному за пилот.
     Секрет ниоткуда не копировать и не создавать.
   - readable, same as payload: True — файл в порядке, но этот Revit
     загрузил расширение без него. Обычно Revit started раньше created/
     modified (файл появился на раздаче после запуска) или Revit не был
     полностью перезапущен после установки. Закрыть ВСЕ окна Revit
     (Get-Process Revit ничего не выводит), запустить Revit заново и
     повторить п. 1–2. После такого перезапуска всё ещё "has none" —
     СТОП с выводом скрипта: Revit не читает файл, который читает
