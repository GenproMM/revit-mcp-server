# Revit MCP Server — карта знаний

Мост между ИИ-ассистентом и Autodesk Revit: 54 MCP-инструмента, разложенных
на два процесса Python, которые общаются по локальному HTTP. С 2026-09-07
регистрация — автообнаружением, есть прогоняемый тестовый уровень
(322 теста, 3 skipped) и архитектура приёма инструментов от разработчиков без доступа
к репозиторию. На 2026-09-10 HEAD исправлен: закрыт контракт `text/plain + parse_request_data`,
раздача вышла из чужого git-репозитория, ошибка установки у пользователей снята.
На 2026-09-17 найдена жалоба про откат правки параметров и исправлена видимость откката.

> [!info] Одна фраза
> MCP-сервер на CPython принимает вызовы от ИИ-клиента и переводит их в HTTP-запросы
> к серверу pyRevit Routes, живущему внутри процесса Revit, где IronPython уже
> дёргает настоящий Revit API.

## Решения

- [[Revit-часть написана на IronPython 2.7 и не может делить код с MCP-частью]] (частично устарела — см. ниже)
- [[Целевой рантайм Revit-половины — IronPython 3, не 2.7]]
- [[Ошибки не выбрасываются, а возвращаются строками]]
- [[Провал ответа определяется только ключом error или явным статусом]]
- [[Каждая транзакция глушит модальные диалоги Revit]]
- [[ElementId читается и создаётся только через хелперы]]
- [[Все инструменты принимают миллиметры, Revit внутри считает в футах]]
- [[Save и SaveAs выполняются вне транзакции]]
- [[Транспорт внедряется в модули инструментов, а не импортируется]]
- [[Один keep-alive HTTP-клиент обслуживает все вызовы]]
- [[Порт 48884 захардкожен, настраивается только хост]]
- [[Регистрация — автообнаружение вместо рукописных списков]]
- [[Изоляция отказа регистрации по домену]]
- [[Разработчики инструментов работают без доступа к репозиторию]]
- [[Регистрация ведётся двумя рукописными списками]] (историческая)
- [[Холодный старт 0.9 с — это пол фреймворка, оптимизировать нечего]]
- [[Тесты — это самостоятельные скрипты, а не pytest-сьют]] (частично устарела — см. новые решения выше)
- [[execute_code остаётся аварийным люком для отсутствующих инструментов]]
- [[Общие параметры определяются по префиксу ForgeTypeId, а не по типу Definition]]
- [[SaveAs детач-модели требует WorksharingSaveAsOptions.SaveAsCentral]]
- [[open_model закрывает воркседы по паттерну имени, переиспользуя конфигурацию из скилла revit-open-links-closed]]
