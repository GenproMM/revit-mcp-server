# Фаза 2 принята как есть с открытым риском AMBIG-04, override оформлен

**Решение.** После живой приёмки 02-18 (8 из 9 критериев, G6 stop) верификатор вернул `gaps_found`. Пользователь сначала ответил `accept` на чекпоинте (записано как принятие риска, override тогда не создавался), затем явно выбрал вариант **«Принять фазу как есть»**. В `02-VERIFICATION.md` оформлен override для SC5/AMBIG-04: статус `passed`, `overrides_applied: 1`, слова пользователя и время записаны. Фаза 2 закрыта (`phase.complete`, 20/20 планов).

**Что остаётся открытым.** AMBIG-04 возвращён в `Pending` (в REQUIREMENTS.md и трассировке): `phase.complete` по умолчанию помечает все требования выполненными, это исправлено вручную. G6 нужно повторить после backlog 999.1 (Revit-сторонняя сериализация обработчика).

**Почему так.** Правило плана требует девяти наблюдённых критериев, поэтому приёмка без override была невозможна; override возможен только по явному решению пользователя, и оно получено. Классификатор не ослабляли: его единственное изменение — локализованное имя «Проект1» ([[Классификатор требовал Project1, а русский Revit называет первый проект Проект1]]).

**Как применять.** При следующем `phase.complete` проверять трассировку: AMBIG-04 оставлять `Pending`. G6 и cross-wire: [[Перекрывающиеся записи в один Revit получают чужой ответ и теряют запись, G6 воспроизведён]].
