<objective>
Turn the tracer's minimal base loader into the full two-layer policy of D-14..D-17 and D-27: strict data
validation of the base file shipped in the payload, an optional operator file on the share applied by overlay
with hot reload (atomic, debounced, never on the event loop), honest states for absent/unreachable/rejected
files, a blocking state for an invalid base, the policy hash that the permit and the status carry, and the
build-time staging of the operator file path.

Purpose: SAFE-09, SAFE-10, and the policy half of SAFE-13 ("a pending approval does not survive an applied
policy change"). D-15: the operator may relax any rule; the immutable minimum is deliberately absent. D-02:
stdlib tomllib only.

Output: `policy.py` (validation, overlay, store), the policy-changed re-check in `approval.py`, tests, the
`MCP_POLICY_FILE` deploy variable, `deploy/policy_tool.py`, the `policy_source` staging in
`deploy/build-payload.cmd` and the base-policy check in `deploy/gate.py`.
</objective>

## Execution rules for every task in this plan

- CPython only in this plan. `policy.py` never prints, never touches stdout, never reads a file at import;
  file reads run inside `asyncio.to_thread` and `asyncio.wait_for(..., READ_TIMEOUT_S)`.
- Never touch the real share or `\\Srv-dfs`: tests use tmp_path files and an injected reader; the deploy
  scripts are only edited and unit-tested, never run against the share.
- Preserve line endings (`deploy/*.cmd` keep theirs). New files LF, UTF-8 without BOM.
- Commit protocol as in 07-01 (pathspec commits; full unit suite green before each commit).
  Prefix `feat(07-04):` / `test(07-04):`.

## Interfaces this plan adds to policy.py

- Vocabularies: `REASONS` (frozenset: create, read, view_state, file_io, document_state, process_local, delete, transform, load_family, edit_family, execute_code, parameter_write, type_parameter, multiple_elements, overwrites_value, facts_unavailable, group_member, shared_parameter_source, family_contents_unchecked, parameter_definition), `CONFIRM_WHEN` (type_parameter, multiple_elements, overwrites_value, facts_unavailable, group_member), `FACTS` (none, parameter, elements, family, load, code), `SETTINGS_RANGES` {"confirm_timeout_s": (30, 900), "permit_ttl_s": (10, 110)}, `SETTINGS_TEXT` = ("shared_parameters_file",), `OPERATOR_ROUTE_KEYS` = ("decision", "reasons", "check", "confirm_when"), `STRUCTURAL_ROUTE_KEYS` = ("method", "document_bound", "facts").
- `validate_base(document) -> None`, `validate_operator(document, base_document) -> None`, `merge(base_document, operator_document) -> dict`, each raising PolicyError with a short message naming the key path only (never file content).
- `POLICY_FILE_ENV = "REVIT_MCP_POLICY_FILE"`, `POLICY_SOURCE_FILE = "policy_source"`, `RELOAD_INTERVAL_S = 2.0`, `READ_TIMEOUT_S = 3.0`, `DEBOUNCE_S = 0.2`; `operator_path(source_dir=None) -> str or None`.
- `class PolicyStore(base_path=None, reader=None, clock=None, source_dir=None)` with `async current(force=False) -> Policy`, `status() -> dict` (keys source, hash, operator_file, operator_state, diagnostic, blocked, blocked_reason, confirm_timeout_s, permit_ttl_s; never raises); operator_state is one of "not_configured", "absent", "pending", "accepted", "rejected", "unreachable".
- Module level: `async def current(force=False)` and `async def status(refresh=True) -> dict` delegate to one lazily created store; `_reset()` drops it (tests only).
