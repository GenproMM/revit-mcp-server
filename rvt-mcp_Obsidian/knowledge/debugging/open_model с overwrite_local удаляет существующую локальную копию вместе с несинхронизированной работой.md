# open_model с overwrite_local удаляет существующую локальную копию вместе с несинхронизированной работой

**Симптом (по чтению кода, не воспроизведено вживую).** `open_model(detach="none")` для центральной модели создаёт локальную копию через `WorksharingUtils.CreateNewLocal`. Если копия по этому пути уже есть, а `overwrite_local` по умолчанию `True`, `_make_local_copy` делает `os.remove(local_path)` (`revit_mcp/worksharing.py:197-199`). Несинхронизированные изменения в старой копии теряются без предупреждения.

**Причина.** `CreateNewLocal` не перезаписывает существующий файл, поэтому код удаляет его заранее. Умолчание выбрано ради «чистой» копии, но при этом теряются данные.

**Как должно быть (решение пользователя 2026-10-25).** Как опция Revit «Добавить штамп даты и времени к существующей копии»: существующая копия переименовывается со штампом, новая создаётся рядом, ничего не удаляется. Заодно умолчание `open_model` меняется с `detach="preserve"` на создание локальной копии. Рабочие наборы все закрыты; если так открыть не удаётся — открыт набор, в имени которого есть «Оси и уровни».
