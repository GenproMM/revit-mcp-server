# AGENTS.md — правила для ИИ-ассистента в этом репозитории

Читается автоматически: Kilo Code, Cursor, Windsurf, Claude Code. Правила ниже
имеют приоритет над твоими привычками. Идентификаторы, пути и код — по-английски,
объяснения — по-русски.

## Главное правило: НЕ создавай файлы вручную

Для новой возможности запусти генератор:

```bash
uv run python scripts/new_tool.py <domain> <tool_name>          # POST, с записью
uv run python scripts/new_tool.py <domain> <tool_name> --get    # только чтение
```

Он создаёт оба файла, добавляет инструмент в манифест и оставляет `TODO` ровно
там, где нужно твоё решение. Регистрировать ничего не надо — обход находит
модули сам.

**Если ты пишешь файл в `revit_mcp/` или `tools/` с нуля — ты делаешь это
неправильно.** Генератор гарантирует соблюдение конвенций по построению;
рукописный файл — нет.

Расширяешь существующий домен? Добавь маршрут и инструмент в его файлы и
допиши имя инструмента в `tests/unit/tool_manifest.txt`.

## Обязательный цикл

```bash
uv run pytest tests/unit          # ОБЯЗАТЕЛЬНО перед каждым коммитом
```

530+ тестов проверяют конвенции механически. **Если тест упал — правило
нарушено. Правь код, а не тест.** Тест правится только если он объективно
неверен, и тогда — с объяснением в теле коммита.

Полная проверка на живой модели:

1. **Полностью закрыть и открыть Revit.** Кнопки Reload недостаточно — она
   валит процесс Revit на первом же запросе.
2. `http://localhost:48884/revit_mcp/status/?verbose=true` — твой домен в
   списке, `health: healthy`.
3. `mcp dev main.py` — вызвать инструмент по-настоящему.

## Два рантайма — не смешивать

Это источник большинства поломок.

| Где | Рантайм | Что можно |
|---|---|---|
| `revit_mcp/`, `startup.py` | **IronPython 2.7** | только `"{}".format(x)`; **никаких** f-строк, `async`, `pathlib`, `list[str]`, аннотаций типов |
| `tools/`, `main.py`, `tests/` | CPython ≥3.11 | всё современное |

f-строка в `revit_mcp/` — это `SyntaxError` при загрузке: домен не
зарегистрируется, инструмент не появится, в логах ничего внятного не будет.

Хелперы в `revit_mcp/` импортируются плоско: `from utils import ...`, **не**
`from .utils import ...`. Это не опечатка, так работает `sys.path` pyRevit.

## Запреты

- **Транзакция без `suppress_warnings(t)` сразу после `t.Start()`.** Без него
  штатное предупреждение Revit открывает модальное окно и вешает сервер
  навсегда — все следующие запросы отваливаются по таймауту, пока человек не
  нажмёт кнопку. Исключение: `Save`/`SaveAs` — **вне** транзакции.
- **Транзакция в читающем маршруте.** Аудит и любое чтение не открывают
  транзакцию вообще.
- **`.IntegerValue` и `DB.ElementId(<int>)`.** Только
  `get_element_id_value()` / `make_element_id()`. Голый int падает на Revit
  2027 с «Multiple targets could match».
- **`print()` в `main.py`** под stdio — ломает протокол. Только `logging`.
- **`raise` из обработчика маршрута.** Всё тело в `try/except`, возврат через
  `routes.make_response(data=..., status=...)`; коды 400 / 404 / 500 / 503.
- **Индексировать результат моста.** Он бывает `dict` **или** строкой
  `"Error: ..."`. Всегда через `format_response(response)`.
- **`execute_revit_code` как способ реализовать задачу.** Это аварийный люк
  для разведки. Рабочее решение — типизированный маршрут.
- **Возвращать `"status": "success"`, пропустив элементы.** Считай пропуски и
  отдавай их числом или списком.
- Размеры наружу — **всегда миллиметры** (`MM_TO_FEET = 1.0 / 304.8`).
- Имена из Revit — через `get_element_name()` / `sanitize_string()`. Кириллица
  обязана дойти целой.

## Докстринг инструмента — это контракт для модели

FastMCP строит схему из докстринга. Это **единственное**, что модель видит перед
вызовом. Пиши для модели, не для разработчика:

1. Одна строка — что это и когда применять.
2. Правила области: что происходит при каждой комбинации входа.
3. Форматы значений с **конкретными** примерами (`["beams", "OST_Walls"]`, а не
   «список категорий»).
4. Форма возврата **с единицами**.
5. Ограничения — прямым текстом. Модель не догадается сама и примет пустой
   результат за доказательство отсутствия.
6. Блок `Args:` со **всеми** параметрами, включая `ctx`.

Эталон — `check_clashes` в `tools/clash_tools.py`. Меняешь поведение — меняй
докстринг **тем же коммитом**.

Инструментов уже 51, и каждый конкурирует за внимание модели. Новый домен —
только с обоснованием, почему это не параметр существующего инструмента.

## Чего не делать без спроса

- Не трогать `format_response` в `tools/utils.py`. Дикт без `status` — это
  **данные**, а не ошибка. Расширение списка признаков ошибки один раз уже
  уехало в прод (`c1231f6`) и спрятало валидные данные за баннером ошибки.
- Не менять `deploy/`. Раскатка на парк станций — отдельная ответственность.
- Не «чинить» отключение `GenproMCP` в `install.cmd`. Это решение, а не баг;
  причина описана в комментарии там же.
- Не переименовывать `revit-mcp-server.extension` и не менять
  `routes.API("revit_mcp")` — это контракты раскатки.
- Не коммитить без прогона `uv run pytest tests/unit`.

## Коммиты

Ветки `feature/<тема>`. Префиксы `fix(server):`, `feat(deploy):`, `docs:`.
**Тело обязательно: симптом → причина → исправление** — из тел коммитов в этом
проекте восстановлена вся база знаний по отладке. Для работы с ИИ — трейлер
`Co-Authored-By`.
