- Gated preamble: the first statements after the docstring are `gate_refusal = gate_or_response(request)`
  and `if gate_refusal is not None:` / `return gate_refusal`, before the document guard and before any
  `try:`. Optional one-line comment above it: "Phase 5 gate (D-01): shared secret and integrity, before
  anything else."
- Import: `from .security import gate_or_response`, relative, next to the other `from .` imports.
- GET routes get nothing. The handler body after the preamble is not edited.
- IronPython 3.4 dialect in `revit_mcp/`; `uv run pytest tests/unit -q` green before every commit;
  explicit pathspec commits only (`git commit -m "<message>" -- <paths>`; never `git add -A` or `.`);
  prefix `feat(05-03):` or `test(05-03):`; end with your session's attribution line.

  keep the route's own validation covered with an envelope-only body (`{}` through gate_support).
