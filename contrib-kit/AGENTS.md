# AGENTS.md — правила для ИИ-ассистента в этом наборе

Читается автоматически: Kilo Code, Cursor, Windsurf, Claude Code. Эти правила
имеют приоритет над твоими привычками.

Здесь **нет репозитория сервера**. Ты собираешь самодостаточный пакет из двух
модулей и отдаёшь его сопровождающему. Ничего, кроме этих двух модулей, в пакет
не входит.

## Главное правило: НЕ создавай файлы вручную

```bash
python revitmcp_kit.py new <domain> <tool>          # инструмент, изменяющий модель
python revitmcp_kit.py new <domain> <tool> --get    # только чтение
```

Генератор создаёт каркас, который заведомо проходит проверку конвенций. **Если
ты пишешь файл в `revit_mcp/` или `tools/` с нуля — ты делаешь это
неправильно.** Ровно эти конвенции проверяет приёмка у сопровождающего, и
рукописный файл почти наверняка что-то нарушит.

## Обязательный цикл

```bash
python revitmcp_kit.py check    # конвенции; ОБЯЗАТЕЛЬНО перед сдачей
python revitmcp_kit.py probe    # прогон на живом Revit
python revitmcp_kit.py pack     # сборка zip для сдачи
```

`check` использует тот же код, что и приёмка. Сдавать пакет с замечаниями
бессмысленно — откажут.

`probe` отправляет текст маршрута в `/execute_code/` **локального** Revit
разработчика и вызывает обработчик на реальной модели. Нужен открытый Revit с
открытой моделью. Это единственный способ убедиться, что код работает: `check`
проверяет форму, а не поведение.

**Не сообщай, что готово, по зелёному `check`.** Пройденные конвенции ничего не
говорят о том, что маршрут возвращает правильные данные.

## Два рантайма — не смешивать

| Файл | Рантайм | Что можно |
|---|---|---|
| `revit_mcp/<domain>.py` | **IronPython 2.7** внутри Revit | только `"{}".format(x)`; **никаких** f-строк, `async`, `pathlib`, `list[str]`, аннотаций типов |
| `tools/<domain>_tools.py` | CPython 3.11+ | всё современное |

f-строка в `revit_mcp/` — это `SyntaxError` при загрузке расширения: домен не
зарегистрируется, инструмент не появится, в логах ничего внятного не будет.

Модуль маршрута должен быть валиден **и как Python 3** — иначе его невозможно
проверить вне Revit. Практически это и означает «пиши на пересечении диалектов».

Хелперы импортируются плоско: `from utils import ...`, **не**
`from .utils import ...`. Так работает `sys.path` pyRevit.

## Запреты

- **Транзакция без `suppress_warnings(t)` сразу после `t.Start()`.** Без него
  штатное предупреждение Revit открывает модальное окно и вешает сервер на всех
  станциях навсегда, пока человек не нажмёт кнопку.
- **Транзакция в читающем маршруте.** Чтение не открывает транзакцию вообще.
- **`.IntegerValue` и `DB.ElementId(<int>)`.** Только
  `get_element_id_value()` / `make_element_id()`. Голый int падает на Revit
  2027 с «Multiple targets could match».
- **`raise` из обработчика.** Всё тело в `try/except`, возврат через
  `routes.make_response(data=..., status=...)`; коды 400 / 404 / 500 / 503.
- **Индексировать результат моста.** Он бывает `dict` **или** строкой
  `"Error: ..."`. Всегда `format_response(response)`.
- **`"status": "success"` с молча пропущенными элементами.** Считай пропуски и
  отдавай их в ответе.
- **`import subprocess`, `socket`, `requests`, `shutil`, `eval`, `exec`,
  работа с файлами.** Приёмка это помечает и требует объяснения. Инструменту
  Revit это не нужно; если кажется, что нужно — сначала спроси.
- **Правки чужих файлов.** Пакет — это ровно два модуля. Приёмка отклоняет
  архив, содержащий что-либо ещё.
- Размеры наружу — **всегда миллиметры** (`MM_TO_FEET = 1.0 / 304.8`).
- Имена из Revit — через `get_element_name()`. Кириллица обязана дойти целой.

## Докстринг инструмента — это контракт для модели

FastMCP строит схему из докстринга. Это **единственное**, что модель видит перед
вызовом. Пиши для модели, не для разработчика:

1. Одна строка — что это и когда применять.
2. Правила области: что происходит при каждой комбинации входа.
3. Форматы значений с **конкретными** примерами (`"Generic - 200mm"`, а не
   «имя типа»).
4. Форма возврата **с единицами**.
5. Ограничения прямым текстом. Модель не догадается сама и примет пустой
   результат за доказательство отсутствия.
6. Блок `Args:` со **всеми** параметрами, включая `ctx`.

`check` не пропустит пакет, в докстринге которого остались `TODO`.

## Если застрял

Скажи прямо и покажи, что именно не сходится. Не подставляй заглушку, которая
проходит `check`, и не помечай задачу выполненной. Молчаливая заглушка в
BIM-инструменте — это неверные данные в модели, которые заметят месяцы спустя.

Вопросы, на которые отвечает только человек: какие категории Revit брать, что
считать ошибкой, а что пустым результатом, и в каких единицах отдавать.
Спрашивай до того, как писать код.
