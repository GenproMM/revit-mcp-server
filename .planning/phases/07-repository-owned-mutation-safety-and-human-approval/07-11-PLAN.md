## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| share (company FOP) -> MCP server | the file that decides which shared parameters are allowed |
| model arguments -> window text | untrusted strings shown to the engineer |
| Revit model state between yes and send | the model can change during the wait |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
