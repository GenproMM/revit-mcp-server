# Транспорт внедряется в модули инструментов, а не импортируется

## Решение

Ни один модуль в `tools/` не импортирует `revit_get` / `revit_post` / `revit_image`.
Они передаются аргументами в функцию регистрации:

```python
def register_clash_tools(mcp, revit_get, revit_post, revit_image=None):
    _ = revit_image  # Acknowledge unused parameter

    @mcp.tool()
    async def check_clashes(...) -> str:
        response = await revit_post("/clash_check/", data, ctx)
        return format_response(response)
```

`main.py` собирает всё в одном месте:

```python
from tools import register_tools
register_tools(mcp, revit_get, revit_post, revit_image)
```

## Обоснование

**Нет циклического импорта.** Хелперы транспорта живут в `main.py`, а `main.py`
импортирует `tools`. Если бы `tools/*.py` импортировали из `main`, получился бы цикл.

**Модуль инструментов не знает про HTTP.** Он получает вызываемые объекты и ничего не
знает про `httpx`, базовый URL или пул соединений. Заменить транспорт можно, не тронув
ни один из 22 модулей.

**Холодный старт.** Импорты подмодулей лежат **внутри** `register_tools`, а не на
верхнем уровне. Это изолирует провал импорта одного домена и держит cold start низким —
см. [[Холодный старт 0.9 с — это пол фреймворка, оптимизировать нечего]].

## Соглашения

Сигнатура регистратора фиксирована:

```python
def register_<домен>_tools(mcp, revit_get, revit_post, revit_image=None)
```

Неиспользуемые внедрённые параметры **подтверждаются явно**, а не игнорируются молча:

```python
_ = revit_image  # Acknowledge unused parameter
```

Это сигнал читателю, что параметр не забыт, а осознанно не нужен.

## Асимметрия, которую стоит знать

`tools/__init__.py` вызывает регистраторы **с разным числом аргументов** — часть
модулей объявляет только то, что использует:

```python
register_status_tools(mcp_server, revit_get_func)                     # только GET
register_family_tools(mcp_server, revit_get_func, revit_post_func)    # GET + POST
register_colors_tools(mcp_server, revit_get_func, revit_post_func)    # GET + POST
register_clash_tools(mcp_server, revit_get_func, revit_post_func, revit_image_func)
```

То есть сигнатуры регистраторов не полностью унифицированы. Добавляя модуль, проверьте
и объявление, и вызов.
