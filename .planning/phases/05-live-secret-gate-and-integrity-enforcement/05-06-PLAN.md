<objective>
Make "closed by default" enforced rather than merely true: an AST sentinel over the real route
inventory fails for any non-GET route that does not open with the gate and is not on the explicit
open-reads list; `scripts/conventions.py` carries the same rule, so the repository suite, the
contributor kit and package intake all reject a forgotten gate; the scaffolds and CONTRIBUTING.md
teach the preamble.

Purpose: D-01 (closed by default via a sentinel test plus the conventions rule, no wrapper), D-02 (the
exact open set), D-03 (boundary routes gated). SEC-01 cannot regress silently; SEC-05 is pinned.

Output: the sentinel test, the tightened Phase 2 inventory test, the conventions rule and its tests,
updated scaffolds and contributor docs.
</objective>
