## Нерешённое и находки

- `/status/` (`revit_status(verbose)`) и `/model_info/` (`get_model_info()`) работают в потоке HTTP-сервера без контекста Revit API; не менялись, `/status/` может быть таким намеренно (должен отвечать во время запуска). Решать по живой проверке.
- `get_element_properties` не показывает значения параметров (ключ `message` схлопывает ответ в «Found N parameters»); G6 читает значение через `old_value` следующей записи.
- Кнопка G5-диагностики отказывается от основного порта (только 48991) — получится коллизия вспомогательных RoutesServer, не доказательство назначения основного порта.
- `get_revit_view` возвращает `str(response)` для не-текстового успеха вопреки докстрингу; `_TOKEN_SHAPE` пропускает токен с завершающим переводом строки (отклоняется как 404, не 400) — мелочи.
- Незакоммичено намеренно: `.planning/ROADMAP.md` (staged вместе с правками фазы 7 из другой сессии), `.planning/REQUIREMENTS.md`, `graphify-out/`, `README.md`, `deploy/*`, `scripts/*`, `startup.py`, `contrib-kit/*`, untracked `tests/unit/test_parallel_installation.py` (починен исполнителем 02-03, принадлежит другой сессии), `.planning/config.json` (содержит `workflow.use_worktrees=false`), `.planning/milestone.lock`, `.planning/state.json`.
- `requirements-completed` во всех итогах пуст осознанно: требования закрываются только после живой приёмки 02-18.
