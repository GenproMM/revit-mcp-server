## Interfaces this plan creates (later plans build on these names; keep them stable)

permit.py (stdlib only: hashlib, hmac, json, secrets, time):
- `PERMIT_PROTOCOL = 1`, `PERMIT_KEY = "permit"`, `ENVELOPE_KEY = "_mcp"`, `KEY_LABEL = b"revit-mcp/permit/v1"`, `MAC_PREFIX = "permit1"`.
- `args_text(data) -> str`: refuses a non-dict with ValueError("request body must be a JSON object to carry the shared-secret envelope") and a dict holding `_mcp` with ValueError("request body already carries the reserved _mcp key; refusing to merge it into the shared-secret envelope") (the two texts `bridge.with_envelope` already uses), then `json.dumps(data, separators=(",", ":"), allow_nan=False)` with the default ensure_ascii=True (pure ASCII text); NaN or Infinity raise ValueError("request body contains NaN or Infinity, which JSON cannot carry").
- `args_hash(text) -> str`: `hashlib.sha256(text.encode("ascii")).hexdigest()`.
- `derive_key(secret) -> bytes`: `hmac.new(secret.encode("utf-8"), KEY_LABEL, hashlib.sha256).digest()`.
- `mac_message(route, a, s, e, n, p) -> bytes`: the seven values `MAC_PREFIX, route, a, s, str(e), n, p` joined by "\n", encoded ASCII.
- `mint(secret, route, args_text, session_token, policy_hash, ttl_s, now=None, nonce=None) -> dict`: keys exactly `v` (1), `r` (route), `a` (args_hash), `s` (session token), `e` (int(now) + ttl_s), `n` (`secrets.token_hex(16)` unless given), `p` (policy hash, 12 hex), `m` (HMAC-SHA256 hex of mac_message under derive_key(secret)).
- `wire_text(args_text, envelope) -> str`: `'{"_mcp":' + json.dumps(envelope, separators=(",", ":")) + ("}" if args_text == "{}" else "," + args_text[1:])`.

revit_mcp/permits.py (verifier; no pyRevit import):
- `PERMIT_PROTOCOL = 1`, `PERMIT_KEY = "permit"`, `KEY_LABEL = b"revit-mcp/permit/v1"`, `WIRE_PREFIX = '{"_mcp":'`, `MAX_TTL = 120`, `SKEW = 5`, `REGISTRY_CAP = 4096`.
- Verdicts: `OK = "ok"`, `MISSING = "missing"`, `MALFORMED = "malformed"`, `UNSUPPORTED = "unsupported_version"`, `BAD_SIGNATURE = "bad_signature"`, `ROUTE_MISMATCH = "route_mismatch"`, `SESSION_MISMATCH = "session_mismatch"`, `ARGS_MISMATCH = "args_mismatch"`, `EXPIRED = "expired"`, `TTL_TOO_LONG = "ttl_too_long"`, `REPLAYED = "replayed"`, `REGISTRY_FULL = "registry_full"`, `NOT_CONFIGURED = "not_configured"`.
- `_LOCK = threading.Lock()`, `_CONSUMED = {}` (nonce -> exp).
- `hmac_sha256(key, msg) -> bytes` (RFC 2104 over hashlib, block size 64, key longer than 64 bytes hashed first), `derive_key(secret) -> bytes`, `normalize_route(path) -> str or None` ("/" + path without query string, stripped of slashes, + "/"), `split_wire(raw) -> (envelope, args_text) or None`, `check_and_consume(raw, route_path, secret, session_token, now=None) -> verdict`.
