## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client -> Revit route | ids, view names, file paths and arbitrary code arrive from the caller |
| Revit API call -> reply | the reply must reflect what the transform, view creation, UI switch, open or code run did |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-18 | Repudiation | transform/create_view bare commits | high | mitigate | commit_and_report + 409; reads after the committed check (Task 1) |
| T-04-19 | Information disclosure | execute_code outcome | medium | mitigate | outcome carries status and Revit failures only, never the code text, output or traceback (those stay in their existing keys) (Task 2) |
| T-04-20 | Elevation of privilege | /execute_code/ itself | high | accept | Unchanged trusted arbitrary-code exception (Phase 2 D-15 decision); this plan only adds reporting |
| T-04-21 | Information disclosure | file paths in open_model outcome | low | accept | the path is the caller's own request |
