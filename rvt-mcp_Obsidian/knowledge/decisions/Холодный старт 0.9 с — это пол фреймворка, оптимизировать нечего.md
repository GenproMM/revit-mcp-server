# Холодный старт 0.9 с — это пол фреймворка, оптимизировать нечего

## Измерение

От спавна процесса до ответа на `initialize` по stdio — **~0.9 с** на машине
разработчика. Замер зафиксирован коммитом `56f6077` и охраняется тестом
`tests/test_init_latency.py` с порогом 2.0 с.

## Из чего складывается

| Компонент | Стоимость |
|---|---|
| Импорт `mcp.server.fastmcp` | ~426 мс |
| Импорт `httpx` | ~290 мс (всё равно тянется транзитивно самим `mcp`) |
| Всё остальное | остаток |

## Вывод

**Ни один несущественный импорт не доминирует, поэтому ленивая загрузка ничего не
даст.** Это не «пока не оптимизировали», а измеренный вывод: 0.9 с — обязательная
стоимость импорта фреймворка. Комментарий в тесте фиксирует именно это, чтобы
следующий читатель не начал заново искать, что вынести в lazy import.

```python
# Floor (~0.9s on dev hw) is the required import cost of mcp.server.fastmcp
# (~426ms) + httpx (~290ms, pulled in transitively by mcp anyway). No
# non-essential import dominates, so there is nothing worth lazy-loading.
# Threshold allows headroom for slower machines / CI.
assert dt < 2.0, "initialize too slow: %.3f s" % dt
```

## Что всё-таки сделано для старта

Импорты подмодулей инструментов лежат **внутри** `register_tools`, а не на верхнем
уровне (`tools/__init__.py`), и то же на Revit-стороне в `startup.py`. Это удерживает
стоимость на минимуме и изолирует провал импорта одного домена.

`httpx.AsyncClient` создаётся **лениво**, при первом вызове, а не при импорте —
см. [[Один keep-alive HTTP-клиент обслуживает все вызовы]].

## Почему порог именно 2.0 с

Запас на медленные машины и CI. Это регрессионный гейт, а не бенчмарк: он ловит
ситуацию, когда кто-то добавил тяжёлый импорт на верхний уровень, а не измеряет
производительность.

> [!note] Обновляя число — обновите комментарий
> Файл хранит измерение и его обоснование рядом с порогом. Расхождение между ними
> обесценивает и то, и другое.

## Оговорка

Это единственный тест, которому **не нужен живой Revit** — он проверяет только
MCP-рукопожатие и запускается где угодно. Второй тест
(`tests/test_model_info_format.py`) требует Revit с открытым документом.
