## Попутно

- Мой `uv run` без `--no-sync` сломал общую `.venv` (`mcp` не импортировался). Причина невозможности uv удалить пакеты — ReadOnly на каталогах site-packages (ACL CodexSandboxUsers). Починено снятием ReadOnly и `uv sync --locked --inexact --reinstall-package …`. Связано: [[Общая venv повреждена при обновлении SDK из-за работающих MCP-сессий]].
- `pyrevit extensions paths forget` и host — [[pyrevit forget не снимает UNC-путь без точного совпадения, без host Routes слушает 0.0.0.0]].
- PowerShell: `(& exe) -match 'x'` при ОДНОЙ строке вывода возвращает `True`, а не строку; писать `@(& exe) -match 'x'`. Поймано тестом gpo-prep.
- Многострочная вставка в консоль PowerShell ломается (перенос строк, обрыв) — поэтому диагностика вынесена в файл `.ps1`.
- Служебная очистка `.git/worktrees/hot-cirrus` по-прежнему даёт Permission denied; на коммиты не влияет.
