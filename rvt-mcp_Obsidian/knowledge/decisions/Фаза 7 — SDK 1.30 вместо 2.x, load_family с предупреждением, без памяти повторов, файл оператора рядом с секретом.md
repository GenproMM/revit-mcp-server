# Фаза 7 — SDK 1.30 вместо 2.x, load_family с предупреждением, без памяти повторов, файл оператора рядом с секретом

**Контекст.** Исследование фазы 7 (`07-RESEARCH.md`) закрыло открытые гейты обсуждения и вынесло на решение пользователя четыре вопроса. Ответы записаны в `.planning/phases/07-repository-owned-mutation-safety-and-human-approval/07-CONTEXT.md` как D-24…D-27.

**Решение.**
- **D-24 — `mcp` 1.30.0 (`>=1.30,<2`), не 2.x.** Elicitation есть с 1.10. Вместе с обновлением: shim `pywin32` в `sys.path` (`libs\win32`, `libs\win32\lib`, `libs\pythonwin`) в `deploy/server.py`, `deploy/gate.py`, `deploy/warm.py` и `structured_output=False` по умолчанию в `audit.install_audited_tools`. Обновление идёт за `checkpoint:human-verify` (план 07-01). Переход на 2.x (`FastMCP` → `MCPServer`, перенос опций, `ClientSession` → `Client`) — отдельная будущая фаза.
- **D-25 — `load_family` остаётся confirm** с явной строкой в окне «общие параметры внутри семейства не проверяются по ФОП». Содержимое `.rfa` до загрузки не проверяется — это записано в границы обхода (SAFE-18), а не закрыто запретом по папкам.
- **D-26 — памяти недавних операций на стороне Revit нет.** Если Hermes после reconnect доставит уже выполненную allow-операцию в новый процесс сервера, она выполнится второй раз без окна. Это остаточный риск, который честно описывается в гарантии критерия 5 (SAFE-16). Confirm-операции защищены новым окном и одноразовым разрешением.
- **D-27 — файл политики оператора `%MCP_SHARE_ROOT%\_build\operator_policy.toml`** рядом с `bridge_secret`, путь подставляется в payload при сборке. ACL «только чтение для обычных пользователей» — требование выкладки, его проверяет оператор; фаза не утверждает, что ACL уже такой.

Принятые по умолчанию рекомендации (Claude's Discretion, пользователь может переопределить): `start_revit`, `discover_revit_targets`, `get_revit_process_status` — allow; клиентский `cancel` → `denied` (`approval_cancelled`), таймаут сервера → `expired`; явная подстановка `document` в тело на confirm-путях; правка `SERVER_INSTRUCTIONS` и docstring'ов входит в фазу; исправление `edit_family` под Revit 2025+ — вне фазы.

**Почему.** 1.30.0 проверен прототипом: полный unit-suite, три транспорта, холодный старт в раскладке payload. 2.x не даёт серверу ничего, но требует миграции `main.py`, `gate.py` и тестов. Остальные три ответа — рекомендации исследования, выбранные ради лёгкости (D-02) и честности формулировок.

**Цена.**
- `uv.lock` добавляет 11 пакетов, включая `pywin32`; payload растёт.
- Холодный старт в payload вырос с ~0.85 до ~1.05 с (порог 2.0 с).
- Повтор allow-операции после reconnect не защищён; дыра ФОП через содержимое семейства остаётся.
