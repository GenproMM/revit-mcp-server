## Decision reconciliations (adopted from 03-RESEARCH.md)

- **C4 (D-06's pair does not transfer 1:1):** `tools/utils.py::_project_response` treats a dict as an
  error when it has a truthy `error` key. `auth_failure()`'s body has one, so as a dict it IS an
  error, unlike the `rolled_back` dict. The pair therefore has three assertions: verbatim string
  passthrough of `Error: 401 - ...`; the real body as a dict renders `ERROR DETAILS`; the alarm that
  a dict with only an `auth` key is not an error. `format_response` itself is not changed (CLAUDE.md:
  never add implicit error signals there).
- **Pitfall 2 (payload cannot import revit_mcp):** `build-payload.cmd` copies only root modules, so the
  client loader lives in `bridge.py` and duplicates the small normalization rule; the parity test is
  what keeps the halves identical.
