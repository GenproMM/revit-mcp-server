# Разметка чата съедает звёздочки в командах PowerShell

**Статус:** обойдено в START-HERE.txt и скриптах.

## Симптом

Тестировщик прислал «вывод» блока диагностики, а там был сам блок, и в нём `'^\suserextensions\s='` вместо `'^\s*userextensions\s*='`. С таким шаблоном блок не находит зарегистрированный путь и даёт ложный результат. Вывода не было вовсе: многострочная вставка в консоль PowerShell (с переносами по ширине окна) не выполнилась как блок.

## Причина

Помощник тестировщика показал команды в чате с Markdown-разметкой: пары `*…*` стали курсивом и исчезли. Отдельно — консоль PowerShell плохо переносит многострочную вставку.

## Исправление

- Все кванторы `*` в командах инструкции заменены на `{0,}` (для .NET regex то же самое); тест `test_operator_instruction_survives_chat_copy_and_covers_the_engine` запрещает `*` в START-HERE.txt.
- Правило для помощника в начале инструкции: команды брать из файла байт в байт, блок `& { … }` запускать целиком, пользователю показывать вывод, а не текст.
- Длинную диагностику — отдельным файлом `.ps1` и одной строкой `powershell -NoProfile -ExecutionPolicy Bypass -File …`, а не вставкой.
- Скрипты для Windows PowerShell 5.1 — только ASCII: файл без BOM с кириллицей 5.1 читает как ANSI.
