# Фаза 3 — конверт _mcp несёт только секрет, сравнение ручное SHA-256 с XOR

**Контекст.** `03-CONTEXT.md` (D-01…D-17) собран 2026-09-23, до фазы 2. Исследование при планировании нашло шесть расхождений с уже отгруженным кодом (таблица Conflicts в `03-RESEARCH.md`). CONTEXT.md не переписывался; согласование записано в планах 03-01, 03-02, 03-03, 03-07.

**Решение (по пунктам).**
- **C1.** Фаза 2 передаёт документ плоским ключом `document` в теле POST (`tools/editing_tools.py:63-66`, `revit_mcp/identity.py:634`). Ключ `_mcp` несёт **только секрет**; `document` в конверт не переносится. Ключи не пересекаются. Идея D-01 «один конверт для document, call_id и секрета» отменена в части `document`; `split_envelope` возвращает весь словарь конверта, чтобы позже туда легли `call_id` и токен одобрения фазы 7.
- **C2.** Фаза 2 запрещает обёртку обработчиков в `startup.py` (`tests/unit/test_phase2_inventory.py:597`). Поэтому логика — набор маленьких чистых функций (`split_envelope`, `check_secret`, `auth_failure`, `evaluate_integrity`, `integrity_failure`), не декоратор. Переписывать ли `request.data` в guard — вопрос фазы 5.
- **C3.** `CryptographicOperations.FixedTimeEquals` отсутствует в .NET Framework 4.8 (Revit 2024) и принимает `ReadOnlySpan<byte>`. Значит, верна ветка «ручное сравнение с задокументированной причиной»: SHA-256 обоих значений, XOR-накопление 32 байт без раннего выхода. Причина пишется в docstring `secret_matches`; живой результат добавляет 03-08.
- **C4.** Тело `auth_failure()` содержит ключ `error`, поэтому пара тестов 401 — из трёх утверждений, а не копия пары `rolled_back`.
- **C5.** Секрет — сетевой барьер против вызовов из LAN, а не защита от того, кто читает шару. Записано в `config.cmd` и CLAUDE.md.
- **C6.** `config.cmd` умеет только `set`; генерирует секрет `deploy/secret_tool.py`.
- Путь `MCP_SECRET_FILE` по умолчанию — `%MCP_SHARE_ROOT%\_build\bridge_secret` (смена — одна строка `config.cmd`).

**Почему так.** Переносить `document` в конверт означало бы менять 31 место в `tools/` и все guard'ы без выгоды. Обёртка в `startup.py` сломала бы инвариант фазы 2. CLR-примитив недоступен на части парка.

**Как применять.** В фазе 5 подключать секрет через существующий per-handler guard `mutation_document_or_response` в `identity.py`, не через `startup.py`. Не путать с [[Под замок все маршруты кроме status, одна общая запись сервера без копий]] — замок и секрет независимы.
