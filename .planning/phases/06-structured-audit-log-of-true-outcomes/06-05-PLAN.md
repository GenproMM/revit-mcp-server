## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP server process -> audit directory | the writer creates, rotates and deletes files on the user's disk |
| MCP server process -> stdout | the stdio protocol stream |
| two server processes -> one audit directory | concurrent writers and pruners share the directory, never a file |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
