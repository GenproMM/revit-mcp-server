`scripts/new_tool.py` has an uncommitted user hunk (the status URL printed near the end of `main()`
now reads `127.0.0.1:48884/genpro_revit_mcp/status/`). A pathspec commit would sweep it into this
plan's commit. Before Task 2, run `git status --porcelain -- contrib-kit/revitmcp_kit.py
CONTRIBUTING.md CLAUDE.md`; if any of them also shows a user change, treat it the same way as
`scripts/new_tool.py`. `$SCR` is a scratch directory outside the repository (your session scratchpad).

```bash
SCR="<your scratchpad>/p04-08"; mkdir -p "$SCR"
git diff -- scripts/new_tool.py > "$SCR/new_tool.full.patch"
# Copy it to $SCR/new_tool.ours.patch (Read, then Write) and delete the user's status-URL hunk,
# keeping every hunk this task made.

git read-tree HEAD
git apply --cached "$SCR/new_tool.ours.patch"
for f in contrib-kit/revitmcp_kit.py CONTRIBUTING.md CLAUDE.md; do
  git update-index --add --cacheinfo "100644,$(git hash-object -w "$f"),$f"
done
git diff --cached --stat HEAD      # must list exactly the four paths
git commit -m "<message>"
unset GIT_INDEX_FILE
git reset -q -- scripts/new_tool.py contrib-kit/revitmcp_kit.py CONTRIBUTING.md CLAUDE.md
git diff -- scripts/new_tool.py    # must show only the user's status-URL hunk
```
