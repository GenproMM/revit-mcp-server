<objective>
Write the instrument for the phase's live gate (plan 04-11): a standalone, one-shot script that runs
the D-11 live set against a freshly restarted Revit through the production bridge, records each raw
reply and the text the model would read, and classifies the record into PHASE4_OUTCOMES_OK or STOP.
Its judging logic and its safety refusals are tested offline now, so the one live run cannot be wasted
on a script bug.

Purpose: D-10 (one full Revit restart at the end of the phase for live criteria 1 and 4), D-11 (one
route per family: `modify_element`, a batch route, `export_ifc`; criterion 4 on `tag_elements`
from the `tags` module, chosen because an unknown id is a side-effect-free skip). Criteria 1-4 of the
ROADMAP and TRUTH-01..04 get their live evidence from this script.

Output: `tests/test_phase4_live_outcomes.py` and its offline tests.
</objective>
