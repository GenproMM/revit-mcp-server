# Фаза 6 — обёртка инструментов в main.py, сегменты без переименования, call_id только при секрете

**Контекст.** Планирование фазы 6 (журнал аудита). Решения D-01…D-20 из обсуждения фиксируют, *что* пишется. Здесь записано, *как* это встраивается в код, и какие открытые вопросы исследования закрыл планировщик. Источники: `.planning/phases/06-structured-audit-log-of-true-outcomes/06-RESEARCH.md`, `06-0*-PLAN.md`.

**Решение.**
- **Обёртка инструментов** ставится из `main.py`: `audit.install_audited_tools(mcp)` подменяет `mcp.tool` и через `__signature__` добавляет keyword-only `user_request`. Внутри `tools.register_tools` её ставить нельзя: тесты инвентаря требуют, чтобы `ctx` был последним параметром. JSON-похожий текст `user_request` возвращается в строку pydantic `BeforeValidator`.
- **Точка записи** — `bridge._dispatch`: имя и сигнатура сохраняются, тело уходит в `_dispatch_core`. `/status/` пишется только из `get_revit_status`. Успех `revit_image` получает метку provenance. Отменённая после отправки POST пишется как `unknown` с `cancelled: true`.
- **Файл журнала** — свой обработчик сегментов без переименования: сегмент 10 МиБ, 10 сегментов на процесс, очистка при старте по возрасту (180 дней), затем по размеру (500 МиБ). Оба лимита настраиваются переменными окружения. Стандартный `RotatingFileHandler` отвергнут.
- **Секрет.** Редактирование в одном месте, до обрезки, в сыром и JSON-экранированном виде, плюс финальный проход по готовой строке. Ошибка писателя попадает в stderr только именем класса, один раз на процесс, и никогда не меняет результат инструмента.
- **`call_id`** кладётся в `_mcp` только когда секрет загружен; закреплённое поведение «нет секрета — нет конверта» сохраняется. Строка `Audit: call_id` есть только у вызовов, которые действительно записались; у `not-sent` её нет.
- **Title из рукопожатия** — только как помеченный запасной `handshake_active_title`, никогда не подставляется в `token` или `path`.
- `audit.py` — в корне, только stdlib при импорте. `bridge.py` импортирует его сразу, чтобы `deploy/gate.py` поймал пропуск в payload.

**Почему.** Каждый вариант проверен прототипом или чтением исходников: обёртка — на mcp 1.9.0 этого репозитория, потеря записей `RotatingFileHandler` — экспериментом с открытым читателем на Windows.

**Цена.**
- Схема каждого из 59 инструментов растёт на одно свойство. Описание свойства короткое, полное правило вынесено в `FastMCP(instructions=...)`.
- Трассер 06-01 трогает 7 файлов — больше рекомендованных 5.
- Критерий 3 (общий `call_id`) доказывается только синтетическим инструментом.
