  and `if gate_refusal is not None:` / `return gate_refusal`, before the document guard and before any
  `try:`. Optional one-line comment above it: "Phase 5 gate (D-01): shared secret and integrity, before
  anything else."
- Open-read preamble: the single first statement after the docstring is `strip_envelope(request)` (an
  expression statement; it returns None and never refuses), before any `try:`.

  other `from .` imports. Never a flat `from security import`, never `import revit_mcp.security`.
