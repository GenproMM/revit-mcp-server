## The record contract (05-12 writes it; this plan judges it)

One JSON record per stage, written outside the repository:
`{"schema": 1, "stage": "match"|"corrupt"|"cleanup", "started_at": <ISO text>, "inputs": {"port": <int>,
"stamp": <text>, "module": <"revit_mcp/<name>.py" or null for match>, "names": {<step id>: <level
name>}}, "posts_sent": <int>, "preflight": {...}, "steps": {<step id>: {...}}}`.

`preflight`: `listeners` (the PID list bridge.listener_snapshot gave for the port), `documents` (count
from GET /documents/), `document` (the one selector), `status_http`, `status` (the parsed /status/
body), `bridge_fingerprint` (bridge.loaded_secret_fingerprint(), 8 hex or null), `repo`
(`secret_file_present`, `manifest_present`, `probe_present`, `module_clean` booleans).

Each step: `{"kind": "direct"|"tool", "route": <route key>, "sent": <bool>, "http": <int or null>,
"body": <parsed JSON reply or null>, "text": <for tool steps the text the tool returned (real
format_response); for direct steps the raw response text, cut to 4000 characters>, "error": <exception
text or null>}`.

| Stage | Step ids in order (POSTs counted) | Expected posts_sent |
|-------|-----------------------------------|---------------------|
| match | n_missing (direct POST /create_level/, no envelope), n_mismatch (direct, wrong secret), n_code (direct POST /execute_code/, no envelope, code "result = 1"), r_levels_open (direct POST /document_levels/, no envelope), r_levels_wrong (direct, wrong secret), b_wrong (tool create_level through the production bridge with its secret replaced by the wrong one), p_create (tool create_level, real secret), p_levels (direct GET /list_levels/), s_status (tool get_revit_status) | 7 |
| corrupt | n_missing (direct POST /create_level/, no envelope), m_create (tool create_level, real secret), m_code (tool execute_revit_code, real secret, code "result = 1"), r_levels_open (direct POST /document_levels/, no envelope), p_levels (direct GET /list_levels/), s_status (tool get_revit_status) | 4 |
| cleanup | p_create (tool create_level, real secret), p_levels (direct GET /list_levels/), s_status (tool get_revit_status) | 1 |

Level names are unique per run: `P5_<STEPID>_<stamp>` (for example `P5_N_MISSING_20261025T101200`),
recorded in `inputs.names`; elevations are distinct values above 90000 mm so they cannot collide with
model levels. `WRONG_SECRET` is a fixed 40-character constant in the script that is never the real
secret (05-12 refuses to run if its fingerprint equals the bridge's).
