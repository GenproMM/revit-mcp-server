# Карта модулей и их размеры

Плоская структура, один уровень, без вложенности внутри `tools/` и `revit_mcp/`.
Всего около 10 000 строк, из них ~8 500 приходится на Revit-половину — и она полностью
не покрыта тестами.

## Дерево репозитория

```
revit-mcp-server/
├── main.py                 # Точка входа MCP-сервера + HTTP-мост к Revit
├── startup.py              # Точка входа расширения pyRevit; регистрирует маршруты
├── extension.json          # Манифест расширения pyRevit
├── pyproject.toml          # Метаданные проекта (mcp[cli], py>=3.11)
├── requirements.txt        # Пришпиленные зависимости MCP-процесса
├── uv.lock                 # Лок-файл uv
├── .python-version         # 3.13
├── tools/                  # Слой MCP-инструментов (CPython, async) — 48 инструментов
├── revit_mcp/              # Обработчики pyRevit Routes (IronPython, sync)
├── tests/                  # Самостоятельные stdio-смоук-скрипты
├── images/                 # Скриншоты для README
├── LLM.txt                 # Длинный справочник для ИИ-потребителей (УСТАРЕЛ)
├── README.md               # Пользовательская установка и каталог инструментов
├── README_UV.md            # Заметки по uv
└── .planning/codebase/     # Документы карты кодовой базы (GSD)
```

## Ключевые файлы

**Точки входа:** `main.py` (транспорт из argv), `startup.py` (`register_routes()` на
уровне модуля, при загрузке расширения).

**Место, куда подключать новое:** `tools/__init__.py` для инструмента,
`startup.py` для маршрута. Забытая строка в любом из списков тихо теряет возможность
без ошибки.

**Ядро логики моста:** `main.py` — `revit_get`, `revit_post`, `revit_image`,
`_revit_call`.

**Нормализация ответа:** `tools/utils.py` — единственная функция `format_response`.

**Хелперы Revit:** `revit_mcp/utils.py` — ElementId, имена, безопасность транзакций.

## Соглашения об именах

- Модули маршрутов: `revit_mcp/<домен>.py` — `mep.py`, `rooms.py`, `clash.py`.
- Модули инструментов: `tools/<домен>_tools.py` — `mep_tools.py`, `room_tools.py`.
- Имена домена совпадают почти всегда. Исключения: `revit_mcp/rooms.py` ↔
  `tools/room_tools.py`; `tools/family_tools.py` ложится на `revit_mcp/placement.py`.
- Эндпоинты: `snake_case` со слэшами с обеих сторон — `/status/`, `/place_family/`,
  `/clash_check/`, `/save_document/`. Исключения с path-параметром:
  `/get_view/<view_name>`, `/element_properties/<element_id>`.
