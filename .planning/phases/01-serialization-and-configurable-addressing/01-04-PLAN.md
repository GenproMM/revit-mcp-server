  <action>
    Create `scripts/probe_handler_overlap.py`, a CPython dev tool (encoding cookie; module docstring stating it is the D-23 experiment, that it deliberately bypasses `bridge.py`'s lock by talking to pyRevit Routes with raw `httpx`, that it must only be pointed at a throwaway or untitled model, and that Revit should be fully restarted afterwards). It lives in `scripts/` so it never ships in the payload (`build-payload.cmd` copies `tests/` but not `scripts/`). Guard execution with `if __name__ == "__main__"` so the unit test can import it.

    Arguments: `--host` (default `127.0.0.1`), `--port` (default 48884), `--sleep` seconds (default 4.0). All HTTP goes through one `httpx.AsyncClient(trust_env=False)` to `http://{host}:{port}/revit_mcp/...`. Every POST carries `Content-Type: text/plain; charset=utf-8` and the body `json.dumps({"code": ..., "description": ...})` — an application/json body would hit pyRevit's broken parse instead of the route.

    Preflight: `GET /revit_mcp/status/` with a 5 s timeout. A transport error prints `OVERLAP_UNREACHABLE target={host}:{port}` and exits 2. A non-200 status prints `OVERLAP_NO_DOCUMENT target={host}:{port} status={code}` and exits 3 (`/execute_code/` needs an open document). No POST is sent in either case.

    `build_code(tag, run_id, log_path, sleep_s)` returns IronPython-3-safe source joined with a bare newline (IronPython `exec` rejects CRLF): `import time`; `time.sleep(<sleep_s>)` only when `sleep_s` is above 0; open `log_path` (embedded with `repr()`) in append mode and write the tag plus a newline; `print("MARK-<tag>-<run_id>")`. The generated code must contain no f-strings — it runs under IronPython at the Python 3.4 language level.

    Two phases, each with its own `run_id` (uuid4 hex, first 8 characters) and its own log file under `tempfile.gettempdir()` named `rmcp_overlap_<run_id>.log`. Phase `M` (mutation vs mutation): POST `/execute_code/` with tag `A` and the sleep at t=0, then tag `B` without the sleep at t=0.5 s. Phase `R` (mutation vs read): POST `/execute_code/` with tag `C` and the sleep at t=0, then at t=0.5 s both `GET /list_levels/` (a route that takes `doc`, so it goes through pyRevit's shared handler) and `GET /status/` (runs on the HTTP thread; measure its elapsed time). Per-request timeout is `sleep + 60` seconds. Pause 2 s between phases. After each phase count the lines per tag in that phase's log file.

    Record one observation per caller as a dict with keys `name`, `kind` (`mutation` or `read`), `status` (int or None), `body` (text), `timed_out` (bool), `error` (str or None), `elapsed` (float). The pure function `classify_phase(observations, markers, runs)` — `markers` maps a mutation name to its marker string, `runs` maps a tag to its count — returns `(verdict, reasons)`. Detection: any `timed_out` → `hang`; a mutation body holding another mutation's marker → `cross-wired-mutation`; in a phase containing a read, a read body holding any marker, or a mutation with status 200 whose body holds no marker → `cross-wired-read`; in a phase with no read, a mutation with status 200 and no marker → `lost-output`; a run count above 1 → `duplicate-run`; a run count of 0 for a mutation that answered 200 → `missing-run`; a non-timeout transport error → `error`. The headline verdict follows the precedence cross-wired-read, cross-wired-mutation, hang, duplicate-run, missing-run, lost-output, error, then `serialized` when nothing was detected. `reasons` lists every detection. `d27_triggered(verdict_r)` returns `verdict_r != "serialized"`.

    Output lines: `CALLER phase=<P> name=<n> status=<s> elapsed=<seconds> got=<markers found, or no-marker, or the first 60 characters of the body>`; `RUNS phase=<P> <tag>=<count> ...`; `STATUS_ELAPSED_S=<seconds>` for phase R; `OVERLAP_VERDICT phase=M verdict=<v>`; `OVERLAP_VERDICT phase=R verdict=<v>`; `OVERLAP_REASONS phase=<P> <reasons>`; `D27_TRIGGER=yes` or `D27_TRIGGER=no`. Exit 0 whenever the experiment completed — the probe records, it does not gate.

    Create `tests/unit/test_probe_handler_overlap.py` (encoding cookie, docstring ending "Needs no Revit."; insert `scripts/` on `sys.path` the way `tests/unit/test_conventions.py` does). Tests, each name starting `test_probe_`: `test_probe_serialized_when_each_caller_gets_its_own_marker`, `test_probe_swapped_mutation_marker_is_cross_wired_mutation`, `test_probe_read_holding_a_marker_is_cross_wired_read`, `test_probe_mutation_with_read_shaped_answer_is_cross_wired_read`, `test_probe_double_execution_is_duplicate_run`, `test_probe_timeout_is_hang`, `test_probe_d27_trigger_only_when_read_phase_not_serialized`, `test_probe_generated_code_is_ironpython_safe` (parse with `ast`; assert no `ast.JoinedStr` node, no carriage return, marker present).
