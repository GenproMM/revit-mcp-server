## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> /execute_code/ | arbitrary IronPython with full doc/DB/clr/System access |
| caller -> /open_model/, /activate_document/, /set_active_view/ | process-level and UI-state changes that redirect the next mutation |
| caller -> open POST reads | must stay available without the secret |

| T-05-20 | Tampering | /open_model/, /activate_document/, /set_active_view/ | high | mitigate | gated preamble; rows assert no open, activation or view switch call (Tasks 1-2) |
