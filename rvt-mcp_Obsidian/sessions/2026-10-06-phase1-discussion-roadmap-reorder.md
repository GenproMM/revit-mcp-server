# Сессия 2026-10-06: Обсуждение фазы 1, перестановка фаз дорожной карты

## Цель сессии
Проверить, достаточно ли фазы 1 для использования нескольких моделей в параллельных сессиях Revit.

## Результат
**Нет.** Фаза 1 даёт только экземпляр, фаза 2 даёт документ. Вместе они дают полный сценарий.

## Основные решения (Phase 1 Context D-01..D-18)

### Модель выбора экземпляра (D-02..D-06)
- Один MCP-сервер на один Revit (`REVIT_PORT` фиксирован при старте)
- Несколько записей в конфиге клиента для нескольких Revit
- Порт в get_revit_status (CPython-сторона)
- Неверный REVIT_PORT → падение при старте

### Сериализация (D-07..D-10)
- Один замок на `host:port` (сегодня один процесс = один замок)
- Очередь для всех POST, кроме явного списка читающих
- execute_code, open_model, save_document всегда ждут

### Бюджет времени (D-11..D-14)
- Таймаут вызова считается после захвата замка
- Ожидание в очереди ограничено таймаутом вызова
- "Ничего не отправлено" при превышении срока
- Одно ctx.info при ожидании

### Приёмка (D-16..D-18)
- Два Revit одновременно на 48884 и 48885
- Проверка автосдвига порта (research flag)
- **Стоп-условие:** если автосдвига нет — переразбираться
