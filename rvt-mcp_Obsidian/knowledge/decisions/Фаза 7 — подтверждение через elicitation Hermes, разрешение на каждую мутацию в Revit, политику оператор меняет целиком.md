# Фаза 7 — подтверждение через elicitation Hermes, разрешение на каждую мутацию в Revit, политику оператор меняет целиком

**Контекст.** Фаза 7 добавляет человеческое подтверждение опасных операций. Безопасность принадлежит этому репозиторию, Hermes не дорабатывается ([[Защита операций Revit принадлежит MCP-репозиторию, не Hermes Fork]]). Источник: `.planning/phases/07-repository-owned-mutation-safety-and-human-approval/07-CONTEXT.md`.

**Решение.**
- **Канал.** Стандартная MCP elicitation через неизменённый `12_GenproAI_HermesFork`: окно в Hermes, ответ идёт серверу от клиента, минуя модель. Клиент без elicitation → операция блокируется. Обновление `mcp` 1.9.0 до версии с elicitation входит в фазу. Windows-окно и TaskDialog отвергнуты.
- **Ожидание.** 5 минут (в политике), до lock моста и без транзакции; потом `expired`.
- **Охват.** Одно «Да» = одна операция с этими аргументами, даже если в Hermes нажали «на сессию / всегда».
- **Окно.** Аргументы + точный быстрый read-only подсчёт из Revit (instance/type, число экземпляров типа, текущее → новое); каскад удаления — «неизвестно».
- **Что подтверждать.** Всегда: удаление, трансформации, общие параметры, `edit_family`, `load_family`, каждый `execute_revit_code`, переопределение параметров (категории, instance↔type, группа параметра, различие по экземплярам группы). Запись параметров — только рискованная (тип, >1 элемента, перезапись непустого, факт неизвестен). Без окна: создание, save, export, link, open, цвета, смена вида.
- **Общие параметры** — только из `\\Srv-dfs\BIM\01_Ресурсы плагинов\2_Shared_parameters\ГП_ФОП2025.txt`; иначе или при недоступном файле — запрет.
- **Политика.** TOML. Базовая в репозитории (payload), файл оператора на share рядом с `MCP_SECRET_FILE`, hot reload. Оператор может менять **любые** правила, включая ослабление. Невалидный файл оператора → базовая политика + диагностика в `get_revit_status`.
- **Revit-сторона.** Расширение требует одноразовое разрешение на каждой закрытой мутации (allow — сервер выдаёт сам, confirm — после «Да»). Выкладка как R3: payload, потом ext. Необратимо после публикации ext.
- **Jev** отложен целиком. **Живая приёмка** — только Hermes Desktop на рабочем ПК в контуре компании.

**Последствия.**
- ROADMAP-критерий 2 становится поведением по умолчанию, формулировку надо поправить.
- Агент, читающий файл секрета, может выпустить разрешение сам — записывается как ограничение, а не скрывается.
- Канал Telegram остаётся недоказанным.
