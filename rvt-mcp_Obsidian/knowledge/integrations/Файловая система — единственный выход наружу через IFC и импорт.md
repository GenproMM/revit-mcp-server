# Файловая система — единственный выход наружу через IFC и импорт

Кроме HTTP-связи с Revit, проект трогает только локальный диск Windows — и всегда
через Revit API, никогда напрямую (за исключением `os.makedirs` для создания
родительских каталогов).

## IFC-экспорт

Маршрут `POST /export_ifc/`, модуль `revit_mcp/interop.py`.

- Версии: `IFC2x3` (по умолчанию) и `IFC4`, выставляется через
  `ifc_options.FileVersion`.
- Опция `ExportBaseQuantities` пробрасывается из payload.
- Можно ограничить экспорт одним видом: имя вида ищется по коллектору `DB.View`
  с проверкой `not v.IsTemplate`, и его `Id` кладётся в `ifc_options.FilterViewId`.
- Выходной каталог создаётся, если его нет; при неудаче — 500 с внятным сообщением.
- Экспорт обёрнут в транзакцию с `suppress_warnings`, при ошибке — откат и переброс.
- Размер файла считается после экспорта через `os.path.getsize` (best-effort).

## Связывание и импорт внешних файлов

Маршрут `POST /link_file/`, тот же модуль.

Поддерживаемые форматы: **DWG, DXF, DGN, SAT, SKP, 3DM, RVT**, с
`DWGImportOptions`, `SATImportOptions`, `SKPImportOptions`.

Форматы SAT / SKP / 3DM (3D-телесные) добавлены специально, чтобы можно было
импортировать реальную геометрию для высокой достоверности модели. Тогда же
исправлена бага с out-параметром — см.
[[link_file передавал None вместо out-параметра и терял импортированный элемент]].

## Загрузка семейств

Маршрут `POST /load_family/`. Грузит `.rfa` с диска через `Document.LoadFamily`, чтобы
его типы стали доступны для `place_family`. Выполняется **вне транзакции** — LoadFamily
управляет своей собственной, как и Save.

Появился из практической проблемы: библиотека семейств в тестовой среде была почти
пустой, ставить мебель и двери было нечем.

## Сохранение модели

Маршрут `POST /save_document/`. Разобран в
[[Save и SaveAs выполняются вне транзакции]] и
[[Базы данных нет — состояние живёт в открытом документе Revit]].

## Экспорт документации

`revit_mcp/documentation.py` — вывод по умолчанию под `USERPROFILE`, с фолбэком на
`HOME`, затем `C:\`. В одном модуле Revit-стороны используется `tempfile` для
промежуточного вывода.

## Картинки видов

Возвращаются inline как base64 PNG, декодируются мостом в
`mcp.server.fastmcp.Image`. Сервером **никогда не сохраняются** на диск. Таймаут для
таких запросов — 60 с вместо обычных 30.

## Риск

Пути из payload идут прямо в вызовы Revit API без валидации. См.
[[execute_code даёт неаутентифицированное исполнение кода внутри Revit]] — там та же
природа проблемы, просто масштаб больше.
