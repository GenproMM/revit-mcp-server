# Фаза 6 — живой шлюз выполнен контроллером по просьбе, фаза остаётся на human_needed

**Контекст.** План 06-07 помечен `autonomous: false`, `gate="blocking-human"`: живой шлюз по правилу D-20 идёт руками инженера, один раз. Контроллер выполнил предпроверку без Revit и остановился с пошаговой инструкцией. Пользователь ответил: «доверяю полную проверку тебе, запусти Revit и выполни проверку самостоятельно».

**Решения.**
1. Контроллер сам провёл репетицию, `run-single` и `run-dual` по одному разу. Правила одного запуска и копий моделей сохранены: копии двух тестовых моделей без совместной работы лежали в scratchpad, не сохранялись, модель пользователя не открывалась.
2. Открытый Revit пользователя контроллер закрыл только корректно (`CloseMainWindow`). Окно не закрылось из-за запроса сохранения, принудительное завершение не применялось, контроллер остановился и спросил. Пользователь закрыл Revit сам.
3. Оба запущенных контроллером Revit остановлены по точному PID после прогона.
4. Фаза не закрыта: верификатор вернул `human_needed` (четыре решения в `06-UAT.md`), `phase.complete` не вызывался, релиз R4 не готовился.

**Почему так.** Явная просьба заменяет «человека за машиной» в рамках правила пользователя (как в фазе 4); но чужой несохранённый сеанс Revit нельзя ломать без явного согласия, поэтому принудительное закрытие не применялось. Решения по границе фазы (принять критерий 3 на синтетике, WR-01…WR-03) остаются за пользователем.

**Как применять.** Живые одноразовые шлюзы без явной просьбы не запускать. Перед запуском закрыть чужой Revit только корректно и при отказе вернуться к пользователю. После прогона останавливать только процессы, которые запустил сам, по точному PID.
