# Исследование Jev и серверной защиты, добавлена фаза 7

## Запрос

Исследовать Jev и аналоги для перехвата опасных операций Revit: перезапись параметров, создание общих параметров, удаление и перемещение элементов. Учитывать существующую связку с Hermes Fork и дать лёгкое решение с редактируемыми правилами.

## Решение пользователя

Первоначальное предложение обязательного gate в Hermes отклонено: **вся безопасность Revit MCP должна принадлежать этому репозиторию**. Hermes не изменяется; возможность использовать его существующий MCP consent UI ещё нужно проверить. См. [[Защита операций Revit принадлежит MCP-репозиторию, не Hermes Fork]].

## Результаты исследования

- Jev — типизированный семантический классификатор, не механизм авторизации/перехвата и не интерфейс подтверждения. Предлагается только как необязательное дополнение к локальным детерминированным правилам.
- Рассмотрены локальные правила, OPA/Rego, ContextForge, Lasso MCP Gateway, LangGraph/LangChain HITL, клиентские hooks, NeMo Guardrails и Agent Scan. Обязательный отдельный gateway/framework для принятого scope не обоснован.
- Выявлены существенные границы: instance → type fallback при записи параметра, каскад удаления известен после эффекта, reload семейства затрагивает экземпляры, dedicated public create/bind shared-parameter tool отсутствует на момент исследования.
- Предложено repo-owned направление: CPython policy/approval и тонкое Revit-side enforcement перед эффектом. Конкретный permit protocol, доверенный канал согласия, replay/TOCTOU и cross-process store ещё не выбраны и не реализованы.
- Один permit должен быть связан с окончательными аргументами, процессом/документом, политикой и сроком; подпись без атомарного single-use учёта недостаточна. UNKNOWN после отправки не даёт права автоматически повторять мутацию.
- Оба execute-code пути остаются trusted arbitrary-code exceptions по D-15. Не обещаем sandbox, защиту от same-user ОС-кода или устранение pyRevit handler cross-wiring одним токеном.
- Не разрешались внешняя передача BIM-данных, включение Jev API, deployment или live Revit операции.
