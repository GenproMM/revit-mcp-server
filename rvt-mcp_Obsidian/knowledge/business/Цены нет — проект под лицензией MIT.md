# Цены нет — проект под лицензией MIT

## Модель распространения

Открытый исходный код, лицензия **MIT**. Ни платных тарифов, ни подписки, ни
лицензионных ключей, ни телеметрии, ни ограничений на коммерческое использование.

Никакой платёжной инфраструктуры в проекте нет и не подразумевается: нет биллинга, нет
регистрации, нет аутентификации вообще
([[execute_code даёт неаутентифицированное исполнение кода внутри Revit]]).

## Стоимость для пользователя

| Компонент | Стоимость |
|---|---|
| Этот MCP-сервер | 0 — MIT |
| pyRevit | 0 — свободный аддон |
| `uv`, Python | 0 |
| **Autodesk Revit** | подписка Autodesk, дорого |
| ИИ-клиент | зависит от клиента и модели |

То есть продукт бесплатен, но работает только внутри дорогой платной экосистемы. Это
типичная позиция инструмента для BIM: пользователь уже платит Autodesk, и добавка
ценности бесплатным слоем автоматизации для него чистая выгода.

Реальная переменная стоимость для пользователя — **токены ИИ-модели**. Сессия работы с
моделью выдаёт десятки вызовов инструментов, и ответы читающих маршрутов могут быть
крупными (пагинации нет — см.
[[Базы данных нет — состояние живёт в открытом документе Revit]]). Это стоит учитывать
как фактическую цену использования.

## Родословная проекта

Проект прошёл через несколько рук, и это видно в метаданных:

| Артефакт | Что указано |
|---|---|
| `extension.json` (автор) | Juan D. Rodriguez / Jean-Marc Couffin |
| `extension.json` (url) | `mcp-servers-for-revit/mcp-server-for-revit-python` |
| `README.md` (автор) | Talal Ahmed |
| `git remote upstream` | `Demolinator/revit-mcp-server` |
| `git remote origin` | `GenproMM/revit-mcp-server` |

Коммит `774b465` — «Update org and repo names to comply with Autodesk Revit trademarks»
— показывает, что переименования были вынужденными: **торговая марка Autodesk Revit**
накладывает ограничения на названия репозитория и организации. Это стоит помнить при
любом ребрендинге или публикации.

`extension.json` при этом **устарел**: он всё ещё указывает старых авторов, старый URL
и имя `revit-mcp-python`, тогда как `pyproject.toml` называет проект
`mcp-server-for-revit`.

См. [[Форк GenproMM — рабочая линия Genpro поверх апстрима Demolinator]].

## Что это означает для планирования

- Вклад в проект возвращается в открытый код, если ветки уходят в апстрим.
- Никаких обязательств по SLA, поддержке или совместимости нет — и это надо учитывать,
  если инструмент встраивается в производственный процесс.
- MIT позволяет форкнуть и держать закрытые правки. Ветка `feature/local-revit-mcp-tools`
  в `GenproMM` — как раз такая рабочая линия.
