# Паттерн регистратора маршрутов

## Форма

Единственный публичный контракт модуля в `revit_mcp/` — функция
`register_<домен>_routes(api)`. Обработчики объявляются **внутри** неё как замыкания.

```python
# -*- coding: UTF-8 -*-
"""Domain Module for Revit MCP — краткое описание домена."""

from utils import get_element_name, get_element_id_value, suppress_warnings
from pyrevit import routes, revit, DB
from System.Collections.Generic import List
import json
import logging
import traceback

logger = logging.getLogger(__name__)


def register_domain_routes(api):
    """Register domain routes with the API."""

    @api.route("/action_name/", methods=["POST"])
    def action_name_handler(doc, request):
        """Что делает + ожидаемый payload."""
        ...

    logger.info("Domain routes registered successfully")
```

## Обязательные элементы

- **`# -*- coding: UTF-8 -*-`** первой строкой — IronPython этого требует.
- **Докстринг модуля** с описанием домена.
- **`logger = logging.getLogger(__name__)`** сразу после импортов.
- **`logger.info("... registered successfully")`** последней строкой регистратора —
  это единственный признак в логе, что модуль загрузился.
- Обработчик называется **`<действие>_handler`** и принимает `(doc, request)` —
  оба аргумента внедряет pyRevit.

## Порядок импортов

1. Локальные хелперы расширения: `from utils import ...` — **плоский** `utils`, не
   `revit_mcp.utils`, потому что pyRevit кладёт каталог модуля в `sys.path`.
2. pyRevit / Revit API: `from pyrevit import routes, revit, DB`,
   `from System.Collections.Generic import List`.
3. Стандартная библиотека: `json`, `logging`, `traceback`.

## Соглашения об именах эндпоинтов

`snake_case` со слэшами с обеих сторон: `/status/`, `/place_family/`, `/clash_check/`,
`/save_document/`.

Исключения — маршруты с path-параметром: `/get_view/<view_name>`,
`/element_properties/<element_id>`. Текстовый path-параметр обязан начинаться с
`unquote` — см. [[get_view возвращал 404 на именах видов с пробелами]].

## Приватные хелперы

Модуль-приватные функции с префиксом `_`: `_resolve_bic`, `_resolve_categories`,
`_multicategory_filter`, `_describe`, `_location_mm` (`revit_mcp/clash.py`).

Приватные константы — `_UPPER_SNAKE`: `_FRIENDLY`, `_DEFAULT_CATEGORIES`.

Приватные классы — с подчёркиванием: `_FailureSwallower` (`revit_mcp/utils.py`).

## Подключение

Модуль сам себя не регистрирует. Импорт и вызов дописываются в `startup.py` →
`register_routes()`. Забыть — значит тихо потерять все маршруты модуля, без ошибки.
См. [[Регистрация ведётся двумя рукописными списками]].
