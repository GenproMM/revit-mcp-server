# open_model по умолчанию создаёт локальную копию, существующую переименовывает со штампом

## Решение

Для workshared-модели `open_model` по умолчанию открывает с `detach="none"` (новая локальная копия через `CreateNewLocal`). Существующая копия по целевому пути не удаляется: она переименовывается в `<stem>_<YYYYMMDD_HHMMSS>.rvt`, при коллизии добавляется `_2`, `_3`. Параметр `existing_local` принимает `timestamp` (умолчание), `overwrite`, `error`.

## Обоснование

Прежнее умолчание `overwrite_local=True` удаляло копию вместе с несинхронизированной работой. Пользователь решил 2026-10-25 вести себя как опция Revit «Добавить штамп даты и времени к существующей копии».

## Принятые уточнения

- **`overwrite_local`** остаётся устаревшим псевдонимом: `true` значит `overwrite`, `false` значит `error`. Новый инструмент всегда шлёт и `existing_local`, и `overwrite_local = (mode == "overwrite")`, чтобы старый маршрут не удалял копию.
- **Папка `_backup`** переименовывается вслед за `.rvt`; если не вышло, `.rvt` возвращается на место.
- **Запасной набор** «Оси и уровни» (без учёта регистра) открывается одной повторной попыткой, только если `close_worksets_matching` не задан.
- **Формат штампа** — предположение, не сверен с Revit.
- Ошибки переименования и `error` при существующей копии дают 500 с `outcome`; неверный `existing_local` даёт 400.
