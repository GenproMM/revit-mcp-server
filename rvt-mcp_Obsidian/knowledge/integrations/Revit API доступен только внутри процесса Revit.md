# Revit API доступен только внутри процесса Revit

Revit API — это .NET-сборки, загруженные в адресное пространство самого Revit. К нему
нет ни REST-интерфейса, ни IPC, ни внешнего SDK, который работал бы из отдельного
процесса. Именно из этого следует вся двухпроцессная архитектура проекта.

## Как до него дотягиваются

Через `pyrevit.DB` / `pyrevit.revit` в каждом модуле `revit_mcp/*.py`. pyRevit
поставляет IronPython 2.7, крутящийся на .NET внутри Revit, и внедряет активный
документ в обработчики маршрутов аргументом `doc`.

Прямой доступ к CLR тоже открыт — `clr` и `System` предымпортированы в пространство
имён исполнения кода (`revit_mcp/code_execution.py`), в том числе для 2027-безопасного
паттерна `DB.ElementId(System.Int64(id))`.

## Единицы измерения

Внутренние единицы Revit — **футы**. Наружу проект выставляет **миллиметры**, и
модули объявляют константу конверсии, например `MM_TO_FEET = 1.0 / 304.8`
(`revit_mcp/tags.py`, `revit_mcp/analysis.py`, `revit_mcp/annotation.py`,
`revit_mcp/detail.py`). Часть модулей делит на `304.8` напрямую (`revit_mcp/building.py`).

Забыть эту конверсию — самая дорогая из уже случившихся ошибок:
[[place_family трактовал миллиметры как футы и уносил семейство на 2.4 км]].

## Совместимость версий

Поддерживаются Revit 2024, 2025, 2026 и 2027, и совместимость держится **в коде**, а не
пиннингом зависимостей. Две функции в `revit_mcp/utils.py` инкапсулируют всю разницу
API — см. [[ElementId читается и создаётся только через хелперы]].

Определение версии автоматическое, через `try`/`except` в рантайме. Конфигурации не
требуется.

**Revit 2027 работает на .NET 10** (против .NET 8 в 2025/2026). Совместимость .NET
берёт на себя pyRevit, поэтому нужна сборка pyRevit с поддержкой 2027. Ни один из 48
инструментов не задействует удалённые в 2027 API: импорт AXM/FormIt, члены
`Mechanical.Zone`, устаревшее создание арматуры, выброшенные свойства
`EnergyDataSettings`.

## Что API не даёт

**Транзакции сериализуются через UI-поток Revit.** Одна изменяющая операция в момент
времени. MCP-сторона допускает до 20 конкурентных HTTP-соединений, но параллелизма это
не даёт — вызовы просто встают в очередь за контекстом Revit API.

**Строки приходят в неопределённой кодировке.** Любое имя из Revit нужно прогонять
через `sanitize_string` перед укладкой в JSON — см.
[[Строки из Revit прогоняются через sanitize_string]].

**Часть коллизий никогда не будет найдена.** `ElementIntersectsElementFilter` не
сообщает о самосоединяющихся бетонных элементах и об элементах без телесной геометрии
(например, арматуре). Это ограничение Revit, не дефект инструмента.
